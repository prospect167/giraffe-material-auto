# 图片去重处理功能 - 完整落地方案文档

## 一、需求概述

### 1.1 业务需求
基于下载的图片，实现智能去重处理功能：
- **去除内容**：多余文字、水印、logo
- **保留内容**：用户指定的文字（如海报标题"生命树"、演员信息等）
- **处理场景**：海报、剧照等包含大量文字信息的图片

### 1.2 图片案例分析
根据提供的海报案例：
- **需要保留**：标题"生命树"、演员"白菊杨紫"
- **需要去除**：出品方信息（"爱奇艺出品"、"帧绮映画MAX"）、播放平台信息、演职员表、logo、水印等

## 二、技术方案

### 2.1 方案选择：多服务商适配器架构

**主方案：即梦API（用户已有会员）**
- ✅ **成本优势**：利用现有会员权益，降低使用成本
- ✅ **国内直接访问**：无需代理，稳定可靠
- ✅ **图像处理能力强**：支持图像理解和编辑

**备选方案：阿里云通义千问视觉大模型**
- ✅ **企业级服务**：稳定性高，适合生产环境
- ✅ **多模态能力强**：图像理解+自然语言处理，能精确理解"去除X但保留Y"的指令
- ✅ **已有集成经验**：项目已使用阿里云服务，SDK和配置熟悉
- ✅ **自动降级**：即梦失败时自动切换，保证服务可用性

### 2.2 技术架构

```
ImageDeduplicationController (接口层)
    ↓
ImageDeduplicationService (业务层)
    ↓
服务商选择器 (自动降级逻辑)
    ├─ JiMengAdapter (主方案 - 即梦API)
    │   └─ 即梦图像处理API
    └─ AliyunTongyiAdapter (备选方案 - 阿里千问)
        └─ 阿里云通义千问视觉API
```

**降级策略：**
1. 优先使用即梦API（主方案）
2. 即梦API失败/超时/不可用时，自动切换到阿里千问
3. 记录使用的服务商，便于监控和成本分析

### 2.3 处理流程

```
1. 接收请求：图片路径 + 保留文字列表
   ↓
2. 读取图片文件 → Base64编码
   ↓
3. 构建AI提示词：
   "请处理这张图片：
   - 去除所有水印、logo和多余文字
   - 但保留以下文字：[preserveTexts]
   - 保持图片的原始风格和清晰度"
   ↓
4. 调用通义千问视觉API（图片+提示词）
   ↓
5. 获取处理后的图片（Base64格式）
   ↓
6. 保存到指定目录
   ↓
7. 返回处理结果
```

### 3.1 接口路径

```
POST /api/v1/deduplication/process
```

### 3.2 请求参数

**请求体（JSON）：**
```json
{
  "imagePath": "/path/to/image.jpg",           // 必填：已下载的图片路径
  "preserveTexts": ["生命树", "白菊杨紫"],     // 必填：需要保留的文字列表
  "removeWatermarks": true,                   // 可选：是否去除水印，默认true
  "removeLogos": true,                        // 可选：是否去除logo，默认true
  "removeExtraTexts": true,                   // 可选：是否去除多余文字，默认true
  "outputDir": "/path/to/output",            // 可选：输出目录，默认与原图同目录
  "outputFileName": "cleaned_image.jpg"       // 可选：输出文件名，默认"cleaned_原文件名"
}
```

**参数说明：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| imagePath | String | 是 | 已下载的图片完整路径 |
| preserveTexts | List<String> | 是 | 需要保留的文字列表，支持多个 |
| removeWatermarks | Boolean | 否 | 是否去除水印，默认true |
| removeLogos | Boolean | 否 | 是否去除logo，默认true |
| removeExtraTexts | Boolean | 否 | 是否去除多余文字，默认true |
| outputDir | String | 否 | 输出目录，默认与原图同目录 |
| outputFileName | String | 否 | 输出文件名，默认"cleaned_原文件名" |

### 3.3 响应结果

**成功响应：**
```json
{
  "code": 200,
  "message": "处理成功",
  "data": {
    "success": true,
    "resultFile": "/path/to/cleaned_image.jpg",
    "originalFile": "/path/to/original_image.jpg",

    }
```

```json
{
  "code": 500,
  "message": "处理失败: 图片文件不存在",
  "data": null

```

**响应字段说明：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| success | Boolean | 是否处理成功 |
| resultFile | String | 处理后的图片路径 |
| originalFile | String | 原始图片路径 |
| preservedTexts | List<String> | 成功保留的文字列表 |
| removedItems | List<String> | 已去除的内容类型 |
| duration | Long | 处理耗时（毫秒） |
| aiProvider | String | 使用的AI服务商 |
| imageSize | Object | 图片大小信息（原始/处理后） |

**文件：** `JiMengAdapter.java`
```java
package com.prospect.giraffe.material.service.deduplication.impl;

import com.google.gson.Gson;
import com.google.gson.JsonObject;
import com.prospect.giraffe.material.config.AiImageProcessingConfig;
import com.prospect.giraffe.material.service.deduplication.IAIImageAdapter;
import lombok.extern.slf4j.Slf4j;
import okhttp3.*;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import org.springframework.util.Base64Utils;

import java.util.List;
import java.util.concurrent.TimeUnit;

@Slf4j
@Service("jimengAdapter")
public class JiMengAdapter implements IAIImageAdapter {
    
    @Autowired
    private AiImageProcessingConfig config;
    
    private OkHttpClient httpClient;
    private final Gson gson = new Gson();
    
    private OkHttpClient getHttpClient() {
        if (httpClient == null) {
            httpClient = new OkHttpClient.Builder()
                    .connectTimeout(config.getTimeout(), TimeUnit.MILLISECONDS)
                    .readTimeout(config.getTimeout(), TimeUnit.MILLISECONDS)
                    .build();
        }
        return httpClient;
    }
    
    @Override
    public byte[] processImage(byte[] imageBytes, List<String> preserveTexts, 
                              Boolean removeWatermarks, Boolean removeLogos, 
                              Boolean removeExtraTexts) throws Exception {
        log.info("使用即梦API处理图片去重，保留文字: {}", preserveTexts);
        
        try {
            // 构建提示词
            String prompt = buildPrompt(preserveTexts, removeWatermarks, removeLogos, removeExtraTexts);
            
            // 图片Base64编码
            String imageBase64 = Base64Utils.encodeToString(imageBytes);
            
            // 构建请求JSON（根据即梦实际API格式调整）
            JsonObject requestJson = new JsonObject();
            requestJson.addProperty("image", imageBase64);
            requestJson.addProperty("prompt", prompt);
            requestJson.addProperty("model", config.getJiMeng().getModel());
            // 根据即梦API文档添加其他必要参数
            
            // 构建请求体
            RequestBody body = RequestBody.create(
                    requestJson.toString(),
                    MediaType.parse("application/json; charset=utf-8")
            );
            
            // 构建请求
            Request request = new Request.Builder()
                    .url(config.getJiMeng().getApiUrl())
                    .post(body)
                    .addHeader("Content-Type", "application/json")
                    .addHeader("Authorization", "Bearer " + config.getJiMeng().getApiKey())
                    .build();
            
            // 执行请求
            try (Response response = getHttpClient().newCall(request).execute()) {
                if (response.isSuccessful() && response.body() != null) {
                    String responseBody = response.body().string();
                    JsonObject jsonResponse = gson.fromJson(responseBody, JsonObject.class);
                    
                    // 检查是否有错误
                    if (jsonResponse.has("error")) {
                        String errorMsg = jsonResponse.get("error").getAsString();
                        throw new Exception("即梦API错误: " + errorMsg);
                    }
                    
                    // 解析返回的图片（根据即梦实际返回格式调整）
                    String resultImageBase64 = extractImageFromResponse(jsonResponse);
                    
                    // 解码返回
                    return Base64Utils.decodeFromString(resultImageBase64);
                    
                } else {
                    throw new Exception("即梦API调用失败: HTTP " + response.code());
                }
            }
            
        } catch (Exception e) {
            log.error("即梦API调用失败: {}", e.getMessage(), e);
            throw new Exception("图片处理失败: " + e.getMessage(), e);
        }
    }
    
    private String buildPrompt(List<String> preserveTexts, Boolean removeWatermarks, 
                              Boolean removeLogos, Boolean removeExtraTexts) {
        StringBuilder prompt = new StringBuilder("请处理这张图片：\n");
        
        if (removeWatermarks) {
            prompt.append("- 去除所有水印\n");
        }
        if (removeLogos) {
            prompt.append("- 去除所有logo\n");
        }
        if (removeExtraTexts) {
            prompt.append("- 去除所有多余文字\n");
        }
        
        if (preserveTexts != null && !preserveTexts.isEmpty()) {
            prompt.append("- 但必须保留以下文字：").append(String.join("、", preserveTexts)).append("\n");
        }
        
        prompt.append("- 保持图片的原始风格、清晰度和色彩\n");
        prompt.append("- 去除文字后，背景要自然融合，不能有明显的修补痕迹");
        
        return prompt.toString();
    }
    
    private String extractImageFromResponse(JsonObject response) {
        // 根据即梦实际API返回格式解析图片
        // 示例：假设返回格式为 {"data": {"image": "base64..."}}
        if (response.has("data")) {
            JsonObject data = response.getAsJsonObject("data");
            if (data.has("image")) {
                return data.get("image").getAsString();
            }
        }
        // 如果返回格式不同，需要根据实际文档调整
        throw new RuntimeException("无法从即梦API响应中提取图片");
    }
    
    @Override
    public String getProviderName() {
        return "jimeng";
    }
    
    @Override
    public boolean isAvailable() {
        return config.getJiMeng().getEnabled() 
                && config.getJiMeng().getApiKey() != null
                && !config.getJiMeng().getApiKey().isEmpty();
    }
}
```

### 4.6 创建业务服务（支持自动降级）

**文件：** `ImageDeduplicationService.java`
```java
package com.prospect.giraffe.material.service;

import com.prospect.giraffe.material.config.AiImageProcessingConfig;
import com.prospect.giraffe.material.dto.DeduplicationRequest;
import com.prospect.giraffe.material.dto.DeduplicationResponse;
import com.prospect.giraffe.material.service.deduplication.IAIImageAdapter;
import lombok.extern.slf4j.Slf4j;
import org.apache.commons.io.FileUtils;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

import java.io.File;
import java.nio.file.Files;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

@Slf4j
@Service
public class ImageDeduplicationService {
    
    @Autowired
    private AiImageProcessingConfig config;
    
    @Autowired(required = false)
    private Map<String, IAIImageAdapter> adapters = new ConcurrentHashMap<>();
    
    public DeduplicationResponse processImage(DeduplicationRequest request) {
        long startTime = System.currentTimeMillis();
        
        try {
            // 1. 验证图片文件存在
            File imageFile = new File(request.getImagePath());
            if (!imageFile.exists() || !imageFile.isFile()) {
                return DeduplicationResponse.builder()
                        .success(false)
                        .duration(System.currentTimeMillis() - startTime)
                        .build();
            }
            
            // 2. 读取图片文件
            byte[] imageBytes = Files.readAllBytes(imageFile.toPath());
            long originalSize = imageBytes.length;
            
            // 3. 获取适配器（支持自动降级）
            IAIImageAdapter adapter = getAdapterWithFallback();
            if (adapter == null) {
                throw new Exception("未找到可用的AI服务适配器");
            }
            
            String usedProvider = adapter.getProviderName();
            log.info("使用AI服务商: {}", usedProvider);
            
            // 4. 调用AI处理（带重试和降级）
            byte[] processedBytes = null;
            Exception lastException = null;
            
            try {
                processedBytes = adapter.processImage(
                        imageBytes,
                        request.getPreserveTexts(),
                        request.getRemoveWatermarks(),
                        request.getRemoveLogos(),
                        request.getRemoveExtraTexts()
                );
            } catch (Exception e) {
                lastException = e;
                log.warn("主服务商 {} 处理失败: {}", usedProvider, e.getMessage());
                
                // 如果启用自动降级，尝试备选服务商
                if (config.getEnableAutoFallback() && !usedProvider.equals(config.getFallbackProvider())) {
                    log.info("尝试切换到备选服务商: {}", config.getFallbackProvider());
                    IAIImageAdapter fallbackAdapter = getAdapter(config.getFallbackProvider());
                    if (fallbackAdapter != null && fallbackAdapter.isAvailable()) {
                        try {
                            processedBytes = fallbackAdapter.processImage(
                                    imageBytes,
                                    request.getPreserveTexts(),
                                    request.getRemoveWatermarks(),
                                    request.getRemoveLogos(),
                                    request.getRemoveExtraTexts()
                            );
                            usedProvider = fallbackAdapter.getProviderName();
                            log.info("备选服务商 {} 处理成功", usedProvider);
                        } catch (Exception fallbackException) {
                            log.error("备选服务商也处理失败: {}", fallbackException.getMessage());
                            throw new Exception("所有AI服务商处理失败", fallbackException);
                        }
                    } else {
                        throw e;
                    }
                } else {
                    throw e;
                }
            }
            
            // 5. 保存处理后的图片
            String outputDir = request.getOutputDir() != null 
                    ? request.getOutputDir() 
                    : imageFile.getParent();
            String outputFileName = request.getOutputFileName() != null
                    ? request.getOutputFileName()
                    : "cleaned_" + imageFile.getName();
            
            File outputFile = new File(outputDir, outputFileName);
            FileUtils.writeByteArrayToFile(outputFile, processedBytes);
            
            // 6. 构建响应
            List<String> removedItems = new ArrayList<>();
            if (request.getRemoveWatermarks()) removedItems.add("水印");
            if (request.getRemoveLogos()) removedItems.add("logo");
            if (request.getRemoveExtraTexts()) removedItems.add("多余文字");
            
            long duration = System.currentTimeMillis() - startTime;
            
            return DeduplicationResponse.builder()
                    .success(true)
                    .resultFile(outputFile.getAbsolutePath())
                    .originalFile(imageFile.getAbsolutePath())
                    .preservedTexts(request.getPreserveTexts())
                    .removedItems(removedItems)
                    .duration(duration)
                    .aiProvider(usedProvider)
                    .imageSize(DeduplicationResponse.ImageSize.builder()
                            .original(originalSize)
                            .processed(processedBytes.length)
                            .build())
                    .build();
                    
        } catch (Exception e) {
            log.error("图片去重处理失败: {}", e.getMessage(), e);
            return DeduplicationResponse.builder()
                    .success(false)
                    .duration(System.currentTimeMillis() - startTime)
                    .build();
        }
    }
    
    /**
     * 获取适配器（优先使用默认服务商）
     */
    private IAIImageAdapter getAdapterWithFallback() {
        // 优先使用默认服务商
        IAIImageAdapter adapter = getAdapter(config.getDefaultProvider());
        if (adapter != null && adapter.isAvailable()) {
            return adapter;
        }
        
        // 如果默认服务商不可用，使用备选服务商
        if (config.getEnableAutoFallback()) {
            adapter = getAdapter(config.getFallbackProvider());
            if (adapter != null && adapter.isAvailable()) {
                log.warn("默认服务商不可用，使用备选服务商: {}", config.getFallbackProvider());
                return adapter;
            }
        }
        
        return null;
    }
    
    private IAIImageAdapter getAdapter(String provider) {
        String beanName = provider + "Adapter";
        return adapters.get(beanName);
    }
}
```

```java
package com.prospect.giraffe.material.controller;

import com.prospect.giraffe.material.dto.ApiResponse;
import com.prospect.giraffe.material.dto.DeduplicationRequest;
import com.prospect.giraffe.material.dto.DeduplicationResponse;
import com.prospect.giraffe.material.service.ImageDeduplicationService;
import lombok.extern.slf4j.Slf4j;
import org.springframework.validation.annotation.Validated;
import org.springframework.web.bind.annotation.PostMapping;

import org.springframework.web.bind.annotation.RequestMapping;

import javax.validation.Valid;

@Slf4j
@RestController
@RequestMapping("/api/v1/deduplication")
@Validated
public class ImageDeduplicationController {
    
    @Resource
    private ImageDeduplicationService deduplicationService;
    
    @PostMapping("/process")
    public ApiResponse<DeduplicationResponse> processImage(@Valid @RequestBody DeduplicationRequest request) {
        log.info("收到图片去重请求: {}, 保留文字: {}", 
                request.getImagePath(), request.getPreserveTexts());
        
        try {
            DeduplicationResponse response = deduplicationService.processImage(request);
            if (response.getSuccess()) {
                return ApiResponse.success("处理成功", response);
            } else {
                return ApiResponse.error("处理失败");
            }
        } catch (Exception e) {
            log.error("图片去重处理异常", e);
            return ApiResponse.error("处理失败: " + e.getMessage());
        }
    }
```
